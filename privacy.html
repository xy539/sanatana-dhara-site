Privacy Policy

Last updated:

This Privacy Policy describes how the Sanatana Dhara application ("we", "our", "the app") handles information when you authorize it via Google OAuth.

1. What the App Does

Sanatana Dhara is a personal automation tool that uploads video content to the YouTube channel @Sanatana_Dhara using the YouTube Data API v3. It is not a public-facing service and is operated solely by the channel owner.

2. Data We Access

The app requests the following Google OAuth scopes:

  • youtube.upload — to upload videos to the channel
  • youtube.readonly — to read channel metadata and video status
  • youtube — to manage channel content

3. Data We Collect and Store

The app stores an OAuth token locally on the operator's private server. This token is used exclusively to authenticate API requests to YouTube. No personal data from any third party is collected, stored, or processed. No user accounts are created. No analytics or tracking is performed.

4. Data Sharing

We do not sell, share, rent, or disclose any data to third parties. API calls are made solely to Google's YouTube Data API v3 on behalf of the channel owner.

5. Data Retention

The OAuth token is retained on the operator's server until manually deleted or revoked. You can revoke access at any time via your Google Account permissions page.

6. Security

The token is stored in a restricted directory on a private server. Access is limited to the channel operator only.

7. Children's Privacy

This app does not collect data from any individuals, including minors.

8. Changes to This Policy

Any updates to this policy will be reflected on this page with a revised date at the top.

9. Contact

For any questions regarding this privacy policy, contact the channel operator via the YouTube channel: youtube.com/@Sanatana_Dhara.
